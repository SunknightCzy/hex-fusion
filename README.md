# hex-fusion

一个基于**六边形网格**的 2048 变体聚变游戏：滑动原子核，让它们按真实的核合成链发生聚变，一路从氢合成到超重核 ★。

单文件实现（`index.html`），无任何外部依赖，打开即玩。核合成链、热量系统、级联聚变动画、粒子特效、音效全部由原生 HTML/CSS/JS 完成。

## 玩法

- **六方向滑动**：将整行原子沿六轴推动（六边形轴向与键盘 QWEASD 一一对应，也支持触屏手势与方向按钮）。
- **聚变代替合并**：与普通 2048 的"相同数字合并"不同，这里只有当相邻原子满足真实核反应配方时才会聚变：
  - ¹H+¹H → ²D（氘）→ ³He → ⁴He → ¹²C → ¹⁶O → ²⁰Ne → ²⁴Mg → ²⁸Si → ⁵⁶Fe（pp 链、三 α 过程、α 俘获、硅燃烧，均为真实核反应）
  - ⁵⁶Fe 之后进入人工轰击路径（中子暴抽象）：3×⁵⁶Fe → ¹⁹⁷Au → ²³⁸U → **★**（游戏终点，超重核）
- **热量系统（"别炸了"模式）**：
  - 每次聚变热度 +1，每回合散热基础值默认 1.5（顶栏「基础散热值」输入框可调，0~30，自动保存）；
  - 热度达到上限触发**堆芯失控**，点击「继续游戏」清空热量后继续（不再判负）。上限在合成 ★ 前为 16，合成 ★ 后提升至 32；
  - 合成出第一个 ★ 后解锁强化：棋盘上每个 ★ 使散热基础值额外 +1，并在其周围随机生成一个 H/D 燃料。

## 特色

- **级联聚变动画**：一步滑动可触发多波连锁聚变，逐波播放；同一操作内后续波次自动加速，最后一波动画播完立即解锁输入，减少等待。
- **多波反应边框提示**：连锁反应进行时地图边框变为橙色脉冲闪烁。
- **显示 / 隐藏反应过程**：可切换为瞬时结算（保留粒子特效与产物生成动画，且不阻塞输入），追求快节奏操作。
- **粒子特效与音效**：内聚粒子、爆裂冲击波、超新星庆典（合成 Au 时全屏爆发）、★ 驱动的**切伦科夫辐射**（★ 越多，地图边框外放射状蓝色光迹越长越强）；3×★ 合并为带**多彩流动光效与彩色光晕**的**超级★**（辐射增益等同 3 颗普通★），合并瞬间边框爆发数秒**磁感线式多色曲线光效**。音效全部由 Web Audio 实时合成，无音频文件。

## 物理真实性说明

游戏的核心聚变链（pp 链、三 α 过程、α 俘获、硅燃烧）对应真实的恒星核合成反应，质量数严格守恒。但以下步骤**不是真实核物理**，仅为游戏设计，已在代码与融合日志中标注：

- **3×⁵⁶Fe + 中子暴 → ¹⁹⁷Au**：铁峰之后的核素不会通过两两聚变生成（吸热反应）；现实中重元素来自中子俘获（超新星 s/r 过程），逐级增加质量数。游戏以"中子暴"一步到位抽象（168 → 197），质量数不守恒。
- **2×¹⁹⁷Au + 中子暴 → ²³⁸U + 2×⁵⁶Fe**：同上，为 r 过程的游戏化抽象（394 → 350），并返还两枚 Fe 作为循环燃料。
- **2×²³⁸U → ★**：完全虚构的游戏终点（476 → 999），★ 并非真实核素。
- **3×★ → 超级★**：完全虚构的游戏设定（三颗星合并为增强星，辐射增益等同三颗普通星）。

融合日志中以上两条人工路径的反应式会附加「（中子暴）」提示。此外氘（²H）在棋盘与日志中统一记作 **²D**（符号 D + 质量角标）。

## 技术说明

- 六边形棋盘采用轴向坐标（axial coordinates），半径 3（37 格）；滑动按巷道（lane）分段处理，支持不规则地图。
- 聚变判定：中心格 + 六邻格内凑齐配方即反应，参与原子必须彼此连通；同波反应用回溯求最大互不重叠集。
- 纯逻辑部分通过 `window.__hex2048Test` 暴露，供无 DOM 环境（如 Node）做测试与模拟。
- 背景标签页节流处理：标签页隐藏时暂停级联聚变、切回时清理积压粒子，避免动画堆积卡顿。
